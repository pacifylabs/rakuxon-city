🔍 Hero Implementation Network Test

Testing Criterion #3: Only one image fetched before load

Follow these steps to verify network behavior:

  1. Open Chrome DevTools (Cmd+Option+I)
  2. Go to the Network tab
  3. Filter by Img to show only images
  4. Check "Disable cache" to force fresh loads
  5. Navigate to the homepage: http://localhost:3000
  6. Watch the network waterfall
✓ Expected behavior (PASS):
  • Only ONE hero image loads before the page load event fires
  • The first image should have Priority: High or fetchpriority="high"
  • Additional hero images (2 & 3) load AFTER the load event completes
  • Check timing: subsequent images should appear in network panel only after ~1-2 seconds

Manual Verification Checklist

  • Height: Hero is 92svh on mobile, 88svh on desktop (not 100vh)
  • Network: Only 1 hero image fetched before load event
  • Contrast: White text readable on ALL three background images
  • Rotation: Images crossfade every 7 seconds (no zoom/Ken Burns)
  • Pause - Scroll: Rotation stops when hero scrolls out of view
  • Pause - Tab: Rotation stops when tab is hidden (switch tabs to test)
  • Pause - Motion: Open DevTools > Rendering > Emulate "prefers-reduced-motion: reduce" - rotation stops
  • Navigation: Pill nav with blur at top, solid bar with border after scroll
  • Feature Panel: Visible on desktop (lg+), hidden on mobile/tablet
  • Champagne: Gold appears ONLY on: "papers" word, "Explore properties" button, and panel seal icons
  • Button Text: "Explore properties" button has CHARCOAL text, not white
  • Clean Seam: Hero ends with clean horizontal edge into ivory section (no wave/diagonal)

Lighthouse Performance Audit

To verify criterion #9:

  1. Build the production site: npm run build
  2. Start production server: npm start or npx serve@latest .next
  3. Open Chrome DevTools Lighthouse tab
  4. Configure:
    • Mode: Navigation
    • Device: Mobile
    • Categories: Performance, Accessibility
    • Throttling: Simulated throttling (default)
  5. Run audit and verify:
    • Performance score ≥ 85
    • Accessibility score ≥ 95
    • LCP (Largest Contentful Paint) < 2.5s
Note: The hero image is the LCP element. If LCP exceeds 2.5s on mobile simulation, check that:
  • The first image has priority and fetchPriority="high"
  • A blur placeholder is present (eliminates layout shift)
  • AVIF/WebP formats are being served
  • Image sizes are within budget (≤250KB mobile, ≤500KB desktop)
