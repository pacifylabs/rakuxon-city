## 📋 Image Type Specific Searches

### For ESTATE Images (Wide aerial/establishing shots)

**Best search terms:**
```
Unsplash: "lagos gated community", "lagos estate aerial"
Pexels: "gated community aerial", "residential development tropical"
Pixabay: "housing estate aerial", "residential community"
```

**What to look for:**
- Multiple buildings visible
- Roads and infrastructure
- Gated entrance (if visible)
- Mix of buildings at different stages
- Aerial or elevated perspective

**Alternative keywords if limited Nigerian results:**
```
"tropical residential development"
"african housing estate"
"gated community tropical climate"
"residential complex aerial view"
```

---

### For HOME Images (Individual properties)

**Best search terms:**
```
Unsplash: "lagos duplex", "nigerian house exterior"
Pexels: "tropical modern house", "african villa"
Pixabay: "modern tropical home", "contemporary african house"
```

**What to look for:**
- Individual detached or semi-detached houses
- Modern architectural style
- Tropical features (large windows, verandas, pitched roofs)
- Mix of luxury and middle-market styles
- 1-2 under-construction frames showing structure

**Alternative keywords:**
```
"tropical luxury villa"
"modern african home exterior"
"contemporary tropical house"
"african residential architecture"
"tropical duplex"
"african terrace house"
```

---

## 💡 Pro Tips

### 1. **Use Advanced Search Filters**

**Unsplash:**
- After searching, use orientation filters (Landscape for estates/homes, Portrait for collage)
- Sort by "Latest" to find fresh content

**Pexels:**
- Use "More options" → "Orientation" → "Landscape" or "Portrait"
- Select "Original" size when downloading

**Pixabay:**
- Filter by "Photos" (not illustrations)
- Select "Large" or "Original" size

---

### 2. **Combine Search Terms**

Instead of just "Lagos", try:
```
"Lagos modern architecture"
"Lagos residential estate"
"Lagos housing development"
"Lagos gated community"
"Lagos luxury home"
```

For generic tropical alternatives:
```
"tropical estate aerial view"
"african residential modern"
"tropical housing complex"
"gated community tropical"
```

---

### 3. **Download Full Resolution**

- **Unsplash:** Click "Download free" → Automatically gets highest res
- **Pexels:** Click "Download" → Select "Original" from dropdown
- **Pixabay:** Click "Free Download" → Select largest size (usually "Original")

---

### 4. **Check Image License**

All three sources (Unsplash, Pexels, Pixabay) offer:
- ✅ Free for commercial use
- ✅ No attribution required (but appreciated)
- ✅ Can modify/resize
- ✅ Can use for website

**However:**
- ❌ Don't claim ownership
- ❌ Don't sell the photos themselves
- ❌ Don't use for competing stock photo services

## ❓ Need Help?

If you're having trouble finding images:

1. **Start broad, then narrow:**
   - Begin with "tropical residential"
   - Then filter to "tropical estate aerial"
   - Finally try "lagos estate aerial"

2. **Mix authentic + generic:**
   - Don't need ALL images to be Nigeria-specific
   - Architectural style + tropical setting = believable

3. **Focus on quality over authenticity:**
   - A high-quality tropical estate photo > low-quality Nigeria-labeled photo
   - Visual consistency matters more than geographic accuracy for stock photos

4. **Consider AI upscaling:**
   - If you find perfect Nigerian property listing photos but low-res
